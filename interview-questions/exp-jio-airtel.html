02Questions and model answers

Q1
Jio: you listed "CNN-based classifier" on your resume. Explain convolution, pooling and why CNNs work for images.
  • Convolution: learned filters slide over the image computing local weighted sums, detecting edges, textures and parts. Weight sharing cuts parameters, and the operation is translation-equivariant.
  • Pooling: downsampling (max/avg) adds some translation invariance and grows the receptive field.
  • Depth: early layers learn edges, middle layers motifs, deep layers object parts. Residual connections (ResNet) allow very deep networks.
  • Be precise about your project: input size, architecture, augmentation, metrics, what failed. The interviewer will probe exactly those claims.
Q2
Airtel: implement a RAG pipeline with LangGraph that decides whether to retrieve.
from typing import TypedDict, List
from langgraph.graph import StateGraph, END

class S(TypedDict): question: str; docs: List[str]; answer: str; route: str

def router(s):   s["route"] = "retrieve" if needs_kb(s["question"]) else "direct"; return s
def retrieve(s): s["docs"] = retriever.invoke(s["question"]); return s
def generate(s): s["answer"] = llm_answer(s["question"], s.get("docs", [])); return s

g = StateGraph(S)
g.add_node("router", router); g.add_node("retrieve", retrieve); g.add_node("generate", generate)
g.set_entry_point("router")
g.add_conditional_edges("router", lambda s: s["route"], {"retrieve": "retrieve", "direct": "generate"})
g.add_edge("retrieve", "generate"); g.add_edge("generate", END)
app = g.compile()
  • Explain: typed state, conditional routing, adding a grader node (is the context relevant? if not, rewrite the query and retry), checkpointing for memory, and tracing.
Q3
How would you control model behaviour in a customer-facing telecom bot?
  • System policy: scope (only telecom account topics), tone, languages, escalation triggers.
  • Guardrails: input filters (abuse, jailbreaks), PII masking, allow-listed tools (bill lookup, plan change with OTP confirmation), output checks (no false promises about refunds).
  • Tool permissions: read-only by default; write actions need user confirmation and an audit log.
  • Evaluation: a red-team test set, resolution rate, CSAT, escalation correctness.

Q5
Design a multilingual customer-care assistant for 400M subscribers.
  • Channels: app chat, WhatsApp, IVR voice (ASR/TTS in 10+ Indian languages).
  • Router: an intent classifier sends frequent simple intents (balance, recharge) to deterministic flows (cheap, fast) and complex ones to an LLM agent with tools and RAG over policies.
  • Scale: autoscaled stateless services, caching of FAQ answers, regional deployments, rate limits; cost control with small models for routing.
  • Quality and safety: an evaluation set per language, human handoff, monitoring of containment rate, CSAT and hallucination flags.

Basic DSA: check whether parentheses are balanced.
def balanced(s):
    pairs, st = {")": "(", "]": "[", "}": "{"}, []
    for ch in s:
        if ch in "([{": st.append(ch)
        elif ch in pairs:
            if not st or st.pop() != pairs[ch]: return False
    return not st
