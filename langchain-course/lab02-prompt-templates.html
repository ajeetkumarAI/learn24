Prompt Templates

⏱ 20 min + hands-on🎯 Beginner🖼 2 diagrams🧪 3 live demos🐍 Python code

Writing prompts with f-strings works for one demo, but breaks in real apps: a missing variable silently sends a broken prompt, and the same prompt gets copied everywhere. Prompt templates are reusable prompts with blanks, roles and validation. In this lab you build them for emails, translation, chat history and few-shot fraud checks.

In this session

  • PromptTemplate and from_template
  • partial: fix some variables in advance
  • ChatPromptTemplate with system and human roles
  • MessagesPlaceholder for chat history
  • Few-shot templates and LengthBasedExampleSelector

01The big idea: a form with blanks

📝

Think of a bank deposit slip. The slip is printed once with blanks for name, account number and amount. Every customer fills their own values. A prompt template is that slip: "Write a {tone} email to {customer_name} about {issue}". Write it once, fill it a thousand times, and the bank (LangChain) refuses a slip with an empty blank.

03Hands-on: run it here

Templates need no LLM at all, so this whole script runs exactly as in Colab. Notice the clear error for a missing variable, and the few-shot chat prompt: 2 examples become 4 messages before the real question.

lab02_prompts.py
from langchain_core.prompts import (PromptTemplate, ChatPromptTemplate, MessagesPlaceholder,
                                    FewShotPromptTemplate, FewShotChatMessagePromptTemplate)
from langchain.messages import HumanMessage, AIMessage

# PromptTemplate + from_template
template = PromptTemplate.from_template("Explain {topic} to a {audience} in 3 bullet points")
print("variables:", template.input_variables)
print(template.format(topic="cloud computing", audience="10 year old kid"))

# missing variable -> clear error (no silent bug like f-strings)
try:
    template.format(topic="UPI")
except KeyError as e:
    print("error: missing variable", e)

# partial
hindi = PromptTemplate.from_template("Translate '{text}' into {language}").partial(language="Hindi")
print(hindi.format(text="Good morning, how are you?"))

# ChatPromptTemplate with roles + history
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful travel assistant."),
    MessagesPlaceholder("history"),
    ("human", "{question}"),
])
history = [HumanMessage("Hi, I am Ajeet. I am planning a trip to Goa."), AIMessage("Nice! How many days is your trip?")]
for m in prompt.format_messages(history=history, question="3 days. What is my name and where am I going?"):
    print(f"  {m.type:6s}: {m.content}")

# few-shot for chat models
examples = [{"input": "Rs 250 grocery, usual city", "output": "LOW"},
            {"input": "Rs 95,000 crypto, new device, 3 AM", "output": "HIGH"}]
few = FewShotChatMessagePromptTemplate(examples=examples,
        example_prompt=ChatPromptTemplate.from_messages([("human", "{input}"), ("ai", "{output}")]))
final = ChatPromptTemplate.from_messages([("system", "Classify transaction fraud risk as LOW, MEDIUM or HIGH. One word."), few, ("human", "{input}")])
print("\nfew-shot chat prompt has", len(final.format_messages(input="Rs 12,000 electronics")), "messages:")
for m in final.format_messages(input="Rs 12,000 electronics, other state, known device"):
    print(f"  {m.type:6s}: {m.content}")

05Tips and common mistakes

MistakeFix
Putting user text inside the system messagekeep rules in system, user data in human: safer against prompt injection
Curly braces in JSON examples break the templateescape them as {{ }}
20 few-shot examples in every calluse an example selector, or 2–3 good examples
Formatting with .format() then building a chainin chains pass the template itself: prompt | llm (Lab 04)

07Summary

  • Templates are reusable prompts with {blanks}; LangChain finds the variables and errors on missing ones.
  • ChatPromptTemplate adds roles; MessagesPlaceholder inserts history.
  • partial fixes some variables early.
  • Few-shot templates teach by examples; selectors keep prompts short.
