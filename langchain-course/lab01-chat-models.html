Every LangChain app starts with one line: llm = ChatGroq(model="openai/gpt-oss-20b"). In this lab you learn to talk to that model the LangChain way: ask one question, stream the answer word by word, send many questions at once, give the model a role with messages, and read the token bill. The same code works for Groq, OpenAI, Gemini, Claude or a free local model.

01The big idea: one remote for every TV

📺

Think of a universal TV remote. Sony, Samsung and LG TVs all work differently inside, but one universal remote has the same buttons for all of them. LangChain’s chat model is that remote: invoke, stream and batch work the same for Groq, OpenAI, Gemini or Ollama. Change the brand, keep your code.

03Hands-on: run it here (no key)

This mirrors the notebook: invoke, read the response object, give roles, few-shot classify, stream and batch. Count the stream chunks: each | is one chunk arriving.

lab01_models.py
from standins import RuleModel
from langchain.messages import SystemMessage, HumanMessage, AIMessage

# In Colab: llm = ChatGroq(model="openai/gpt-oss-20b")
llm = RuleModel(rules={
    "daily life": "Google Maps uses AI to predict traffic and suggest the fastest route to office.",
    "gravity": "Gravity is the Earth's hug that never lets go! Drop your phone and it says hello to the floor.",
    "taste was bad": "NEGATIVE",
    "mumbai rains": "Grey clouds over Marine Drive,\nvada pav and cutting chai,\nlocal trains run, umbrellas fly,\nMumbai smiles at the monsoon sky.",
    "what is ai": "AI is making computers do tasks that need human intelligence.",
    "what is ml": "ML is a part of AI where computers learn patterns from data.",
    "deep learning": "Deep learning uses many-layered neural networks to learn from huge data.",
})

# 1. invoke
response = llm.invoke("Give me a short example of AI use in daily life?")
print(type(response).__name__, "->", response.content)
print("usage:", response.usage_metadata)

# 2. messages with roles
messages = [SystemMessage("You are a funny teacher. Answer in 2 lines."), HumanMessage("What is gravity?")]
print("\nteacher:", llm.invoke(messages).content)

# 3. few-shot with AIMessage examples
messages = [
    SystemMessage("Classify the review as POSITIVE or NEGATIVE. One word only."),
    HumanMessage("The food was amazing"), AIMessage("POSITIVE"),
    HumanMessage("Delivery was very late"), AIMessage("NEGATIVE"),
    HumanMessage("Packaging was good but taste was bad"),
]
print("few-shot:", llm.invoke(messages).content)

# 4. stream word by word
print("\nstream: ", end="")
chunks = 0
for chunk in llm.stream("Write a 4-line poem on Mumbai rains"):
    print(chunk.content, end="|", flush=True); chunks += 1
print(f"\n({chunks} chunks)")

# 5. batch many questions
questions = ["What is AI?", "What is ML?", "What is Deep Learning?"]
for q, r in zip(questions, llm.batch(questions)):
    print(q, "->", r.content)

Runs here without any API key. A small stand-in plays the LLM (RuleModel or ScriptedModel from standins.py), so every output below is from a real run of this code. In Colab you swap one line: llm = ChatGroq(model="openai/gpt-oss-20b").

Read the response: .content is the text, .usage_metadata is the bill. Groq counts real tokens; the stand-in just counts words, so your numbers in Colab will differ. Every provider fills the same fields, which is the point of LangChain.

05Switch provider in one line

any_provider.py
from langchain.chat_models import init_chat_model

llm = init_chat_model("groq:openai/gpt-oss-20b", temperature=0)      # Groq
llm = init_chat_model("google_genai:gemini-2.5-flash")                # pip install langchain-google-genai
llm = init_chat_model("openai:gpt-4o-mini")                           # pip install langchain-openai
llm = init_chat_model("ollama:llama3.1")                              # free, runs on your laptop

print(llm.invoke("Capital of Maharashtra?").content)                   # same line for all

07Summary

  • A chat model takes messages and returns an AIMessage.
  • invoke for one answer, stream for live typing, batch for many, ainvoke for web servers.
  • System sets rules, Human asks, AI messages can be few-shot examples.
  • temperature=0 for facts, higher for creativity; max_tokens caps length.
  • usage_metadata shows tokens; llm.profile shows what the model can do.
  • init_chat_model("provider:model") switches provider in one line.
