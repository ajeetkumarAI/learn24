Chains with LCEL & Runnables

⏱ 20 min + hands-on🎯 Beginner🖼 2 diagrams🧪 3 live demos🐍 Python code

A chain joins steps so the output of one becomes the input of the next. LCEL (LangChain Expression Language) writes it with the pipe |, exactly like Linux: prompt | llm | parser. In this lab you build sequential blog writers, a review analyser that runs three chains at once, a router that sends coding questions to a coding chain, and a fallback for when a model fails.

In this session

  • What a chain is and why the | pipe
  • prompt | llm | StrOutputParser()
  • Sequential chains: output of one → input of next
  • Passthrough, Parallel, Lambda and Branch
  • Fallbacks and retry for production
  • Stream and batch a whole chain for free

01The big idea: a factory assembly line

🏭

Think of a dosa counter. One person pours batter, the next adds masala, the last folds and serves. Each person does one job and passes the plate on. A chain is that line: prompt fills the template, the LLM writes, the parser cleans up. You can add, remove or swap one station without touching the others.

03Hands-on: run it here

Every runnable from the notebook, with real outputs. The stand-in LLM answers by keyword, so even batch and parallel runs are repeatable.

lab04_lcel.py
from standins import RuleModel
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough, RunnableParallel, RunnableLambda, RunnableBranch

llm = RuleModel(rules={
    "blog title": "Smart Farms: How AI Is Changing Indian Agriculture",
    "blog intro": "From Punjab's wheat fields to Kerala's spice gardens, AI is quietly helping farmers...",
    "summarise": "Clean room and polite staff, but unreliable WiFi.",
    "sentiment": "neutral",
    "keywords": "clean room, polite staff, WiFi",
    "'coding' or 'general'": "coding",
    "python code": "text[::-1]  # slicing reverses a string",
    "2 lines": "Sunlight scatters off air molecules. Blue light scatters most, so the sky looks blue.",
    "tweet": "Monsoon is here! Chai, pakoras and the smell of first rain. #Monsoon",
}, default="OK")

chain = PromptTemplate.from_template("Write a tweet about {topic}") | llm | StrOutputParser()
print("1 chain     :", chain.invoke({"topic": "monsoon"}))
print("2 + lambda  :", (chain | RunnableLambda(lambda t: {"words": len(t.split())})).invoke({"topic": "monsoon"}))

title_chain = PromptTemplate.from_template("Give one catchy blog title about {topic}. Only the title.") | llm | StrOutputParser()
blog_chain = PromptTemplate.from_template("Write a 100-word blog intro for the title: {title}") | llm | StrOutputParser()
print("3 sequential:", ({"title": title_chain} | blog_chain).invoke({"topic": "AI in Indian agriculture"}))
print("4 assign    :", RunnablePassthrough.assign(title=title_chain).invoke({"topic": "AI in Indian agriculture"}))

p = lambda t: PromptTemplate.from_template(t) | llm | StrOutputParser()
analyzer = RunnableParallel(summary=p("Summarise in 1 line: {text}"), sentiment=p("Sentiment (positive/negative/neutral): {text}"),
                            keywords=p("Give 3 keywords, comma separated: {text}"))
print("5 parallel  :", analyzer.invoke({"text": "The hotel room was clean and staff were very polite, but the WiFi kept disconnecting."}))

class_llm = RuleModel(rules={"reverse": "coding"}, default="general")
classify = PromptTemplate.from_template("Is this question about 'coding' or 'general'? One word.\nQuestion: {question}") | class_llm | StrOutputParser()
router = RunnablePassthrough.assign(kind=classify) | RunnableBranch(
    (lambda x: "coding" in x["kind"].lower(), p("Answer with a short Python code example: {question}")),
    p("Answer simply in 2 lines: {question}"))
for q in ["How to reverse a string in Python?", "Why is the sky blue?"]:
    print("6 router    :", q, "->", router.invoke({"question": q}))

class Broken(RuleModel):
    def _generate(self, *a, **k): raise ConnectionError("model-that-does-not-exist")
safe = Broken().with_fallbacks([RuleModel(default="fallback worked")])
print("7 fallback  :", safe.invoke("Say: fallback worked").content)

07Summary

  • LCEL joins runnables with |: prompt | llm | parser.
  • Every chain gets invoke, stream, batch for free.
  • Dict / RunnableParallel run branches together; Passthrough.assign keeps input and adds keys.
  • RunnableLambda for Python steps, RunnableBranch for routing.
  • with_fallbacks and with_retry make chains production-safe.
