01The big idea: a dashboard, a memory and a speed limit

🚗

Think of a car on the Mumbai–Pune expressway. Callbacks are the dashboard: speed, fuel, warnings. The cache is remembering the route, so you don’t ask Google Maps again. The rate limiter is the speed limit, so you don’t get fined (HTTP 429). LangSmith is the dashcam: a full recording of every trip, for when something goes wrong.

03Hands-on: run it here

Callbacks, token streaming, cache, rate limiter and concurrency, timed for real. The stand-in waits 0.8 s per call, like a network round trip, so you can see the cache and concurrency effects.

lab15_production.py
import time, asyncio
from standins import RuleModel
from langchain_core.callbacks import BaseCallbackHandler
from langchain_core.caches import InMemoryCache
from langchain_core.globals import set_llm_cache
from langchain_core.rate_limiters import InMemoryRateLimiter

# a stand-in with 0.8 s of fake network delay, so timings look like a real API
llm = RuleModel(default="India has 22 official languages listed in the Constitution.", delay=0.8)

class MyLogger(BaseCallbackHandler):
    def on_chat_model_start(self, serialized, messages, **kwargs):
        self.start = time.time(); print("🚀 LLM started")
    def on_llm_end(self, response, **kwargs):
        usage = response.generations[0][0].message.usage_metadata
        print(f"✅ LLM finished in {time.time() - self.start:.1f}s | tokens: {usage}")
llm.invoke("Tell me a fun fact about India", config={"callbacks": [MyLogger()]})

class PrintTokens(BaseCallbackHandler):
    def on_llm_new_token(self, token, **kwargs): print(token, end="|")
print("tokens: ", end="")
for _ in RuleModel(default="Snow peaks touch the sky.").stream("Himalayas", config={"callbacks": [PrintTokens()]}): pass
print()

set_llm_cache(InMemoryCache())
for i in (1, 2):
    t = time.time(); llm.invoke("What is the capital of Japan?")
    print(f"call {i}: {time.time() - t:.1f} s" + ("  (from cache, no API cost)" if i == 2 else ""))
set_llm_cache(None)

limited = RuleModel(default="hi", rate_limiter=InMemoryRateLimiter(requests_per_second=0.5, check_every_n_seconds=0.1, max_bucket_size=1))
start = time.time()
for i in range(3):
    limited.invoke(f"hi {i}"); print(f"rate-limited call {i + 1} finished at {time.time() - start:.0f} s")

questions = [f"Give one fact about number {i}" for i in range(1, 6)]
t = time.time(); [llm.invoke(q) for q in questions]; seq = time.time() - t
async def main(): return await asyncio.gather(*[llm.ainvoke(q) for q in questions])
t = time.time(); asyncio.run(main()); par = time.time() - t
t = time.time(); llm.batch(questions, config={"max_concurrency": 2}); b2 = time.time() - t
print(f"5 questions: one by one {seq:.0f} s | async gather {par:.0f} s | batch(max_concurrency=2) {b2:.0f} s")
🚀 LLM started ✅ LLM finished in 0.8s | tokens: {'input_tokens': 7, 'output_tokens': 9, 'total_tokens': 16} tokens: Snow |peaks |touch |the |sky.|| call 1: 0.8 s call 2: 0.0 s (from cache, no API cost) rate-limited call 1 finished at 2 s rate-limited call 2 finished at 4 s rate-limited call 3 finished at 6 s 5 questions: one by one 4 s | async gather 1 s | batch(max_concurrency=2) 2 s

06Summary

  • Callbacks hook into start, end, error and new-token events.
  • set_llm_cache makes repeated identical calls instant and free.
  • InMemoryRateLimiter spaces out calls to respect provider limits.
  • Async gather and batch(max_concurrency=…) serve many requests at once.
  • LangSmith tracing needs only environment variables.
