03Hands-on: your first GenAI app

Let us build “Explain Like I’m 10”: type any topic, pick a level, and an LLM explains it. We use Streamlit, which turns a Python script into a web page (Session 3 covers it in more detail).

app.py
# app.py: a tiny GenAI app.  Run:  streamlit run app.py
import os
import streamlit as st
from openai import OpenAI

st.set_page_config(page_title="Explain Like I'm 10", page_icon="💡")
st.title("💡 Explain Like I'm 10")

def get_key():
    if os.getenv("OPENAI_API_KEY"):              # local: from your .env / environment
        return os.getenv("OPENAI_API_KEY")
    try:
        return st.secrets["OPENAI_API_KEY"]      # cloud: from Streamlit secrets
    except Exception:
        return ""

api_key = get_key()
if not api_key:
    st.warning("Add OPENAI_API_KEY to your environment or to Streamlit secrets.")
    st.stop()
client = OpenAI(api_key=api_key)

topic = st.text_input("What should I explain?", placeholder="e.g. How does UPI work?")
level = st.select_slider("Level", ["Child", "Student", "Professional"], value="Student")

if st.button("Explain") and topic:
    with st.spinner("Thinking..."):
        reply = client.chat.completions.create(
            model="gpt-4o-mini",
            temperature=0.3,
            messages=[
                {"role": "system", "content": f"Explain topics simply for a {level.lower()}. Max 120 words."},
                {"role": "user", "content": topic},
            ],
        )
    st.write(reply.choices[0].message.content)

Install and run it:

terminal
pip install streamlit openai
export OPENAI_API_KEY="sk-..."      # Windows PowerShell:  $env:OPENAI_API_KEY="sk-..."
streamlit run app.py
No API key yet? Create one at platform.openai.com (it needs a small prepaid balance). Many providers, such as Google Gemini or Groq, also offer free tiers with OpenAI-style APIs. Session 3 shows how to keep keys safe.
  • st.text_input and st.select_slider create the input boxes.
  • The system message tells the model how to behave; the user message is the topic.
  • temperature=0.3 keeps answers focused (Session 24 explains why).
  • If no key is found, the app shows a warning and stops instead of crashing.

05Summary

  • Main roles: GenAI Engineer, LLM Engineer, AI Product Engineer, LLMOps Engineer.
  • The course goes foundations → transformers → building real apps.
  • A GenAI app can be ~30 lines: Streamlit UI + one LLM API call.
  • Deploy from GitHub to Streamlit Community Cloud and keep the key in Secrets, never in code.
