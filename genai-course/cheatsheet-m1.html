Module 1 cheat sheet: Introduction to the Program

The big picture of AI, the jobs it creates, your first deployed GenAI app, and a clean working setup.

All modules📖 Glossary

Key ideas

  • AI ⊃ Machine Learning ⊃ Deep Learning ⊃ Generative AI. S1 →
  • ML learns rules from data; traditional code follows rules a person wrote. S1 →
  • NLP understands language, GenAI creates content, agents take actions with tools. S1 →
  • A GenAI app can be ~30 lines: Streamlit UI + one LLM API call. S2 →
  • One virtual environment per project; keys in .env, never in code. S3 →

Common mistakes

  • Committing an API key or .env file to GitHub.
  • Installing everything into one global Python.
  • Deploying a public app with no spending limit on the API key.
  • Calling every chatbot an “agent”: agents use tools and act.
