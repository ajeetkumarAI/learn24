We now know how attention works. In this session, let us put the full transformer together, from input words to output words, and solve one surprising problem: attention has no idea about word order unless we tell it.

01The transformer, end to end

The original 2017 transformer was built for translation. It has two towers: the encoder reads the full input sentence, and the decoder writes the output sentence one token at a time, looking back at the encoder’s understanding.

The original paper used 6 encoder layers and 6 decoder layers, d_model = 512, and 8 attention heads. We will open up each block in Session 21. Today, let us focus on the small box at the bottom: Embedding + Position.

02Why word order must be injected

Self-attention compares every token with every token and takes a weighted sum. Nothing in that maths says which token came first. If you shuffle the words, each word gets exactly the same attention result, just in a different place. In other words, plain attention sees a sentence as a bag of words.

🚆

Like seat numbers on a train ticket. The passengers (words) are the same, but the seat number tells you exactly where each one sits. Positional encoding gives every word its seat number.

RNNs never needed this because they read words in order. Transformers read everything at once, so we must add position information to each embedding before the first layer.

03Sinusoidal positional encoding

The original transformer uses sine and cosine waves of different speeds. For position pos and dimension index i:

PE(pos, 2i) = sin( pos / 10000^(2i/d) )    PE(pos, 2i+1) = cos( pos / 10000^(2i/d) )

The first dimensions change quickly (like the seconds hand of a clock), and later dimensions change slowly (like the hour hand). Together, they give every position a unique pattern.

🕰️

Like reading a clock. The seconds hand alone repeats every minute, but seconds + minutes + hours together give a unique time. Fast and slow waves together give a unique position.

Why this design?

  • Unique: every position gets a different vector.
  • Bounded: values stay between −1 and 1, the same scale as embeddings.
  • Relative distance is easy: for any fixed offset k, PE(pos + k) is a fixed rotation of PE(pos), so the model can learn “3 words before” easily.
  • No training needed, and it can in principle be computed for any length.

04Learned and modern position methods

Sinusoidal encoding is not the only option. Here is what popular models use:

MethodHow it worksUsed inWatch out
SinusoidalFixed sine/cosine pattern added to embeddingsOriginal TransformerWorks, but rarely used in new LLMs
Learned absoluteA trainable vector for each position 0…N−1BERT (512), GPT-2 (1,024)Cannot go beyond the max length it was trained with
RoPE (rotary)Rotates query and key vectors by an angle based on position, so attention scores depend on relative distanceLlama, Mistral, Qwen, GemmaNeeds scaling tricks (e.g. YaRN) to stretch context
ALiBiAdds a penalty to attention scores that grows with distanceBLOOM, MPTSimple; extrapolates well to longer inputs

05Code: sinusoidal encoding in NumPy

positional_encoding.py
import numpy as np

def positional_encoding(max_len, d_model):
    pos = np.arange(max_len)[:, None]             # (max_len, 1)
    i = np.arange(0, d_model, 2)[None, :]         # even dimension indices
    angle = pos / (10000 ** (i / d_model))
    pe = np.zeros((max_len, d_model))
    pe[:, 0::2] = np.sin(angle)                   # even dims: sine
    pe[:, 1::2] = np.cos(angle)                   # odd dims: cosine
    return pe

pe = positional_encoding(50, 16)
print(pe.shape)
print(pe[:3, :4].round(3))                        # first 3 positions, first 4 dims
(50, 16) [[ 0. 1. 0. 1. ] [ 0.841 0.54 0.311 0.95 ] [ 0.909 -0.416 0.591 0.807]]

Then you simply add it: x = token_embeddings + pe[:seq_len]. Some implementations also multiply embeddings by √d_model first so the position signal does not overpower them.

06Summary

  • The transformer has an encoder (reads input) and a decoder (writes output), joined by cross-attention.
  • Attention alone is order-blind, so position must be added to each token.
  • Sinusoidal encoding uses fast and slow waves to give each position a unique, bounded pattern.
  • BERT and GPT-2 learn positions; modern LLMs mostly use RoPE.
