Graphs: BFS & DFS

⏱ 15 min🎬 Interactive visualizer💻 Python · Java · C++ · JavaScript🧩 5 practice problems

Model the problem as nodes and edges, then explore with breadth-first or depth-first search. This covers grids, islands, connectivity and shortest paths in unweighted graphs.

Modelling

A graph is a set of nodes connected by edges, which can be directed or undirected, weighted or unweighted. Interview graphs are often hidden: a grid (each cell is a node, neighbours are edges), word ladders (words that differ by one letter), states of a puzzle, course prerequisites.

Store a graph as an adjacency list: adj[u] = [v1, v2, …]. It uses O(V + E) memory, which is better than a V × V matrix for sparse graphs.

BFS or DFS?

BFS (queue) DFS (stack / recursion)
Order ring by ring from the start as deep as possible, then backtrack
Shortest path in unweighted graphs ✅ yes ❌ no
Memory O(width) O(depth)
Natural for minimum steps, multi-source spreading (rotting oranges), level problems connectivity, flood fill, cycle detection, topological order, backtracking

Both are O(V + E). On an m × n grid that is O(m·n).

The template you will reuse forever

  1. Build the adjacency list (or use the grid directions).
  2. Keep a visited set, and mark nodes when you enqueue them (not when you dequeue), so nothing is added twice.
  3. Loop over every node if the graph may be disconnected, counting components as you go.

Multi-source BFS: push all sources at once (every rotten orange, every gate) and expand layer by layer; the layer number is the distance to the nearest source.

Code template

from collections import deque

def bfs(adj, start):
    dist = {start: 0}
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if v not in dist:              # mark when enqueuing
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

def count_components(n, adj):
    seen, comps = set(), 0
    def dfs(u):
        stack = [u]; seen.add(u)
        while stack:
            x = stack.pop()
            for v in adj[x]:
                if v not in seen:
                    seen.add(v); stack.append(v)
    for u in range(n):
        if u not in seen:
            comps += 1; dfs(u)
    return comps

Common mistakes

  • Marking visited too late (on dequeue) in BFS, which adds duplicates and can blow up the queue.
  • Forgetting disconnected components: loop over every node.
  • Recursion depth on big grids (10⁶ cells): use an iterative stack or BFS.
Check yourself: why does BFS give shortest paths only in unweighted graphs? BFS counts edges. With weights, a path with more edges can be cheaper, so you need Dijkstra (non-negative weights) or Bellman–Ford.
