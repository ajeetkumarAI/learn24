Linked Lists

⏱ 14 min🎬 Interactive visualizer💻 Python · Java · C++ · JavaScript🧩 6 practice problems

Nodes joined by pointers: O(1) insert and delete once you are at a node. Master pointer surgery, dummy heads and the fast/slow technique.

The idea

A singly linked list is a chain of nodes, each holding a value and a next pointer. There is no random access (finding the k-th node is O(k)), but inserting or deleting after a known node is O(1). Interview questions test whether you can rewire pointers without losing part of the list.

Five techniques that solve almost every list problem

  1. Dummy head: a fake node before the head, so deleting or inserting at the front is not a special case.
  2. Reverse in place with prev, curr and next (see the animation).
  3. Fast and slow pointers: fast moves 2, slow moves 1. Use them to find the middle, detect a cycle (Floyd’s algorithm) or find the cycle start.
  4. Gap of n: move one pointer n steps ahead to find the n-th node from the end in one pass.
  5. Merge two sorted lists by always attaching the smaller head; this is the core of merge sort on lists and of Merge k Lists.

Harder problems combine them. Reorder List = find middle + reverse second half + weave. Palindrome List = middle + reverse + compare.

Code template

class ListNode:
    def __init__(self, val=0, next=None):
        self.val, self.next = val, next

def reverse(head):
    prev, curr = None, head
    while curr:
        nxt = curr.next
        curr.next = prev
        prev, curr = curr, nxt
    return prev

def middle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    return slow

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            return True
    return False

Complexity

Traversal O(n). Insert or delete after a known node O(1). Search O(n). All five techniques use O(1) extra space.

Common mistakes

  • Losing the rest of the list: save next before changing curr.next.
  • Null-pointer errors: check fast and fast.next before fast.next.next.
  • Returning the old head after reversing: return prev.
Check yourself: how do you detect a cycle in O(1) space? Floyd’s algorithm. Move slow by 1 and fast by 2; if they ever meet, there is a cycle. If fast reaches null, there is no cycle.
