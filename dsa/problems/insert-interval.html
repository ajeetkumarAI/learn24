85. Insert Interval

MediumGreedy & Intervals✓ SolvedAlso on LeetCode ↗

intervals is sorted by start and has no overlaps. Insert newInterval, merging where needed, and return the result (still sorted, without overlaps).

Example 1

Input: intervals = [[1,3],[6,9]], newInterval = [2,5]
Output: [[1,5],[6,9]]

Example 2

Input: intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
Output: [[1,2],[3,10],[12,16]]
Hint 1

Three phases: intervals ending before the new one, intervals overlapping it, and the rest.

Intervals

Approach 1: Linear three-phase scan ✅

Copy, absorb, copy.

⏱ Time O(n)💾 Space O(n)

Reference solution for Linear three-phase scan (time O(n), space O(n)). Each solution passes every test in all four languages.

class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        res, i, n = [], 0, len(intervals)
        s, e = newInterval
        while i < n and intervals[i][1] < s:        # entirely before
            res.append(intervals[i]); i += 1
        while i < n and intervals[i][0] <= e:       # overlapping: absorb
            s, e = min(s, intervals[i][0]), max(e, intervals[i][1]); i += 1
        res.append([s, e])
        res.extend(intervals[i:])                   # entirely after
        return res
class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {
        List<int[]> res = new ArrayList<>();
        int i = 0, n = intervals.length, s = newInterval[0], e = newInterval[1];
        while (i < n && intervals[i][1] < s) res.add(intervals[i++]);
        while (i < n && intervals[i][0] <= e) { s = Math.min(s, intervals[i][0]); e = Math.max(e, intervals[i][1]); i++; }
        res.add(new int[]{s, e});
        while (i < n) res.add(intervals[i++]);
        return res.toArray(new int[0][]);
    }
}
