Domain 1 traps

Trap How to beat it
Transparency vs accountability Understanding and explaining = transparency; people responsible and overseeing = accountability
Inclusiveness vs fairness Fairness = equal outcomes across groups; inclusiveness = access for everyone (disabilities, languages)
Classification vs object detection Detection gives locations (bounding boxes)
OCR vs captioning OCR reads text; captioning describes the scene
Key phrases vs entities Entities have categories (Person, Location…)
Temperature on reasoning models Reasoning models use reasoning effort, not temperature
“Agent” for every chatbot Use an agent only when tools, actions or multi-step work are needed

Domain 2 traps

Trap How to beat it
Model name vs deployment name in code Code uses the deployment name
Project endpoint vs resource endpoint Foundry SDK and agents use the project endpoint; Language, Speech and Content Understanding use the resource endpoint
Stateless models Keep history yourself, use previous_response_id, or use an agent conversation
File search vs code interpreter Documents → file search; maths, charts, CSV analysis → code interpreter
Speech: recognizer vs synthesizer Recognizer = audio → text; synthesizer = text → audio
Voice and style control speech_synthesis_voice_name and SSML
Vision input vs image generation Understanding an image needs a model with image input; creating needs an image-generation model
Content Understanding is async POST analyze → Operation-Location → poll until Succeeded
Prebuilt vs custom analyzer Common document types → prebuilt (for example invoices); your own fields → custom field schema

Worked case study: Contoso Bank

Contoso Bank wants to (1) answer customer questions from its fee schedule PDF, (2) analyse recorded support calls for sentiment and complaint categories, (3) extract data from loan application forms, and (4) let visually impaired customers hear their balance. The bank requires keyless authentication and wants the least custom code.

(1) Which approach answers questions from the fee schedule? An agent in Foundry with the file search tool (the PDF uploaded as knowledge), or a model grounded on the document (RAG).
(2) Which services analyse the calls? Azure Speech (speech-to-text) plus Azure Language (sentiment, key phrases, summarisation), or a Content Understanding audio analyzer with fields such as Sentiment and ComplaintCategory.
(3) Which service extracts fields from the loan forms? Azure Content Understanding with a document analyzer and a custom field schema.
(4) Which capability reads the balance aloud, and which responsible AI principle does it support? Azure Speech text-to-speech; inclusiveness.
How do the apps authenticate without keys? Microsoft Entra ID: DefaultAzureCredential with a managed identity (in Azure) or the developer’s sign-in, plus a role assignment such as Azure AI User.
