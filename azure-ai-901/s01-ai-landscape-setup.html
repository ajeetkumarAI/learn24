AI, machine learning and deep learning

Think of three circles, one inside the other.

Term What it is Everyday example
Artificial intelligence (AI) Any software that does something we would call “intelligent”: reasoning, perceiving, understanding language, making decisions A chatbot that answers banking FAQs
Machine learning (ML) A way to build AI: the system learns patterns from data instead of following hand-written rules A model that predicts loan default from past loans
Deep learning (DL) ML with neural networks of many layers; great at images, audio and text Face unlock, speech recognition, translation

A model is the learned result: a function that takes an input (an image, a sentence, a row of data) and produces an output (a label, a number, new text). Training creates the model; inference is using it.

Classic ML tasks you should recognise:

  • Regression: predict a number (house price, monthly sales).
  • Classification: predict a category (fraud / not fraud, spam / not spam).
  • Clustering: group similar items without labels (customer segments).

Generative AI and agentic AI: what changed

Generative AI models create new content (text, images, code, audio) instead of only labelling existing content. They are built on very large neural networks called foundation models; the text ones are large language models (LLMs). You talk to them with a prompt.

Agentic AI goes one step further. An agent is a model plus instructions, tools and knowledge, so it can plan, call tools (search a document, run code, call an API) and complete a multi-step task, not just reply once.

Traditional ML Generative AI Agentic AI
Output A label or number New content Actions + content
Interaction Feed data, get a prediction Prompt → response Goal → plan → tool calls → result
Example Fraud score “Write a polite reply to this complaint” “Check this customer’s policy document and open a ticket if the claim is valid”

Why it matters: one general model can now do summarisation, translation, extraction and Q&A that used to need a separately trained model for each task.

Real-world use cases

  • BFSI: KYC document extraction, fraud alerts explained in plain language, customer-support assistants, call-centre speech analytics.
  • Healthcare: summarising clinical notes, transcribing doctor–patient conversations, triage chatbots (with strict human oversight).
  • Retail: product descriptions, visual search, review sentiment, demand forecasting.
  • Education: personalised tutors, auto-generated quizzes, speech-to-text for accessibility.

Azure basics you need on day one

  • Microsoft Entra ID tenant: your organisation’s identity directory (users, groups, sign-in).
  • Subscription: the billing container. Everything you create is charged to a subscription.
  • Resource group: a folder for related resources. Delete the resource group and everything inside goes with it, which is the easiest way to clean up after a lab.
  • Region: the data-centre location (for example Sweden Central, East US 2, Central India). Not every model is available in every region, so check the model catalog before choosing.
  • Resource: one service instance. For this course the key one is the Microsoft Foundry resource, which gives you a project to deploy models and build agents, plus access to Foundry Tools (Azure Language, Azure Speech, Azure Content Understanding and more).

Pricing awareness. Most AI services are pay-as-you-go: you pay per token (text models), per minute of audio, per image or per page. A new Azure free account includes starting credit for the first 30 days, and Azure for Students gives credit without a credit card. Set a budget alert in Cost Management, and delete lab resource groups when you finish.

Naming you will see. Microsoft Foundry was previously called Azure AI Foundry, and before that Azure AI Studio. Foundry Tools is the new name for what used to be called Azure AI services (and before that, Cognitive Services). The exam uses the new names.

Set up your Python environment

You need Python 3.10 or later, VS Code, and the Azure CLI (for keyless sign-in).

# 1) create and activate a virtual environment
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 2) install the packages used across the course
pip install azure-ai-projects azure-identity openai python-dotenv

# 3) sign in so DefaultAzureCredential can use your account
az login

Keep secrets out of your code with a .env file in the project folder:

# .env  (never commit this file: add it to .gitignore)
FOUNDRY_PROJECT_ENDPOINT=https://<your-resource>.services.ai.azure.com/api/projects/<your-project>
FOUNDRY_MODEL_NAME=<your-deployment-name>

import os
from dotenv import load_dotenv

load_dotenv()                                   # reads .env into environment variables
endpoint = os.environ["FOUNDRY_PROJECT_ENDPOINT"]
print("Endpoint loaded:", endpoint[:40] + "...")

API keys vs keyless authentication

API key Keyless (Microsoft Entra ID)
How Send a secret key with every request Sign in (az login, managed identity); the SDK gets a token
Python api_key=os.environ["KEY"] DefaultAzureCredential()
Risk Key can leak; must be rotated No secret in code; access controlled by Azure roles (RBAC)
Recommended for production No Yes

Check yourself

A bank wants a system that reads past loan applications and predicts whether a new applicant will default. Is that generative AI? No. It predicts a category from data, so it is classic machine learning (classification). Generative AI creates new content.
What is the difference between a subscription and a resource group? A subscription is the billing boundary. A resource group is a logical folder inside a subscription that groups related resources so you can manage and delete them together.
Why is keyless authentication preferred over API keys? There is no secret to leak or rotate; access is granted through Microsoft Entra ID identities and Azure role assignments, which can be audited and revoked.
What is the passing score for AI-901, and which domain carries more weight? 700 out of 1000. Domain 2 (implementing AI solutions with Microsoft Foundry) carries 55–60%.
