Session 12: Mock Exam 2 & Exam Strategy

⏱ 10 min read📘 Live-session notes☁️ Microsoft Foundry

The second timed mock and its review, then the strategy that adds marks without extra study: time management, scenario questions, eliminating wrong options, the exam rules about Microsoft Learn, and a walkthrough of booking and the exam sandbox.

▶ Open the AI-901 Exam Practice page and take Mock Exam 2 under timed conditions, then review it with the method from Session 11.

Time management

  • About 45 minutes of exam time for roughly 40–60 questions: aim for under a minute per question on the first pass.
  • First pass: answer everything you know quickly; flag anything that needs thought.
  • Second pass: return to the flagged questions.
  • Never leave a question blank; there is no penalty for a wrong answer.
  • Some sections (for example a case study, or a set of questions with the same scenario) may not allow you to go back once you move on. Read the on-screen instructions at the start of each section.

Reading scenario questions

  1. Read the last line first: what exactly is being asked? (“Which service…”, “What should you do first?”, “Which TWO…”)
  2. Underline the constraints: least development effort, most cost-effective, without writing code, real time, must keep data in the EU.
  3. Spot the trigger words (Sessions 2–4): extract fields from forms → Content Understanding; spoken → speech; bounding boxes → object detection; human oversight → accountability.
  4. Count the answers: “Each correct answer presents part of the solution” means select several; the wording tells you how many.

Eliminating wrong options

  • Remove options that belong to a different modality (a speech service for an image problem).
  • Remove options that do more work than needed when the question asks for the least effort (custom training when a prebuilt analyzer or a model prompt is enough).
  • Remove outdated names if a current Foundry option is offered.
  • Between the last two, ask: “Which one directly produces the output described?”

Question formats you will meet

Format How to approach it
Multiple choice Eliminate, then choose
Multiple answers Judge each option on its own: true or false for this scenario
Yes / No statements (hot area) Treat each statement separately; it is common for all three to be “Yes” or all “No”
Drop-down completion Read the whole sentence with each option in place
Drag and drop / matching Match the items you are sure of first; options may be used once, more than once, or not at all
Code completion Know the key class and method names: AIProjectClient, get_openai_client, responses.create, conversations.create, TextAnalyticsClient.analyze_sentiment, SpeechConfig, SpeechRecognizer, SpeechSynthesizer, the Content Understanding analyze + poll pattern

Can you use Microsoft Learn during the exam?

No. Not for AI-901. Microsoft allows access to Microsoft Learn during role-based (Associate and Expert) exams, but not during Fundamentals exams. Prepare to answer everything from memory and hands-on experience. That is why the labs matter: if you have done it, you can recognise it.

For later exams (for example AI-102 / AI-103-level role-based exams) Learn access can help with a specific fact, but searching costs time from the same exam clock. Use it only for one or two precise lookups, never to learn a topic.

Booking walkthrough and the exam sandbox

  1. Go to the AI-901 exam page on Microsoft Learn and select Schedule exam. Sign in with the Microsoft account you want your certification on (use a personal account you will keep).
  2. Complete your certification profile. The name must match your government ID exactly.
  3. Choose Pearson VUE: an online proctored exam from home, or a test centre. Pick a date and time and pay (the exam fee is paid to Microsoft/Pearson VUE, not included in course fees). Look for student discounts or free-voucher offers from Microsoft events.
  4. For online exams: run the system test in advance, use a private room with a clear desk, a webcam and a stable connection, and check in about 30 minutes early.
  5. Try the exam sandbox (aka.ms/examdemo) to practise the interface: navigation, flagging, review screen and question types.

Check yourself

Can you open Microsoft Learn during the AI-901 exam? No. Learn access is only available for role-based exams, not Fundamentals exams.
A question asks for the solution with the “least development effort”. You are torn between a custom-trained model and a prebuilt capability. Which do you usually choose? The prebuilt capability (or prompting a deployed model). It meets the need with the least work.
In a Yes/No statement set, should your answer to statement 1 influence statement 2? No. Evaluate each statement independently.
