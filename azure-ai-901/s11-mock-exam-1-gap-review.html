Session 11: Mock Exam 1 & Gap Review

⏱ 10 min read📘 Live-session notes☁️ Microsoft Foundry

Sit the first timed, full-length mock exam, review every question with its reasoning, analyse your score by domain and skill, and revise the weak areas: both the concepts and the Foundry hands-on steps behind them.

▶ Start here: open the AI-901 Exam Practice page and choose Mock Exam 1 (40 questions, 45 minutes). Use timed mode with no notes, exactly like the real exam.

Before you start

  • Use a quiet 45-minute slot. Close other tabs and put your phone away.
  • Do not pause the timer. On the real exam you cannot.
  • Answer every question; there is no negative marking. Flag doubtful questions and return to them if time allows.

How to review a mock (the most important hour of the course)

For every question, right or wrong, ask three things:

  1. Why is the right answer right? Say it in one sentence using the exam’s vocabulary (“sentiment analysis returns confidence scores…”).
  2. Why is each wrong option wrong? Most AI-901 distractors are real Azure features used in the wrong place (for example OCR offered for a sentiment scenario).
  3. Was it a knowledge gap or a reading mistake? Reading mistakes (missing “NOT”, “most cost-effective”, “minimise development effort”) are fixed with technique; knowledge gaps need revision.

Most common gaps after Mock 1

  • Confusing transparency with accountability.
  • Picking object detection when the question only needs classification (or the reverse).
  • Forgetting that code calls the deployment name.
  • Mixing up the project endpoint (/api/projects/<name>, for the Foundry SDK and agents) with the resource endpoint (for Language, Speech and Content Understanding).
  • Not knowing which tool an agent needs: file search (documents) vs code interpreter (calculations and data files) vs function calling (your own actions).
  • Thinking a chat model remembers previous calls without history.

Check yourself

Your Mock 1 score is 64% overall, but 45% in Content Understanding. What do you do first? Re-read Session 10, redo Lab 6 (analyzers, schema, polling the result) and then retake the Content Understanding topic drill on the practice page.
Why review the questions you answered correctly? Some were lucky guesses. Explaining why each option is right or wrong turns a guess into reliable knowledge.
