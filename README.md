# Learn24

**See how AI works, one step at a time.**

Learn24 is a free collection of animated, step-by-step lessons on GenAI, AWS cloud, Agentic AI, AI Security, AI System Design and AI frameworks. Every lesson is an interactive animation you can pause, replay and click through, with real-world examples from banking and fintech.

🌐 **Live site:** [learn24-lilac.vercel.app](https://learn24-lilac.vercel.app)
👤 **Created by Ajeetkumar**, AI engineer

## 📄 Resume builder (`/resume`)

A free, ATS-friendly resume builder for AI, data and software roles, built into Learn24. No sign-up: everything is stored in the visitor's browser (`localStorage` key `learn24-resume`).

- **8 templates:** ATS Pro, Classic, Modern, Banner, Minimal, Compact, Executive (header band, Executive Summary, Core Competencies grid) and Two-column (tinted sidebar). Layout styles are adapted from Ajeetkumar's Data Science Resume Bundle. Colour, font, size, spacing and margins are adjustable.
- **9 sample resumes** (fictional people) by level: intern/fresher, analyst, GenAI engineer, ML engineer, data engineer, BFSI data scientist, career switcher and principal/lead. Each opens in a matching template.
- **Project story format:** optional Domain and Type fields, and bullets that start with `Problem:`, `Scope:`, `Solution:` or `Impact:` get a bold label.
- **ATS match:** paste a job description to see the matched and missing skills (168-skill dictionary with aliases), other repeated words, and format checks. Missing skills can be added with one click.
- **Resume score:** a 100-point checklist covering contact details, headline, summary, bullet quality (action verbs, numbers, length, weak phrases), skills, dates, length and ATS-safety. Each suggestion has a "Fix →" link.
- **Bullet ideas:** action verbs, bullet templates by role, and a Problem → Impact template.
- **Cover letter:** a draft generated from the resume and the job description, editable and exportable to PDF.
- **Learn24 import:** ready resume bullets for the 10 portfolio projects and AI-901 labs 3–6, earned certificates, the DSA solved count, and the AI-901 mock score. Project and lab pages have an "Add this project to my resume" button (`resume/index.html#import=<topic>/<lesson>`).
- **Export:** text-based PDF (print to A4), JSON (re-importable; JSON Resume files are also accepted) and plain text. Multiple resume versions can be kept: duplicate one to tailor it per job.

Build: `python3 build_resume.py` writes `assets/resume-data.json` and `resume/index.html`. The app itself is `assets/resume.js` and `assets/resume.css`.

### 💼 Live AI Jobs

[learn24-lilac.vercel.app/jobs](https://learn24-lilac.vercel.app/jobs) shows fresh AI, GenAI, ML and data roles from several platforms in one list, with filters (role, India / remote, posted within, platform), search, saved jobs, "new" badges and auto-refresh every 15 minutes. Apply buttons open the original post. One-click searches on LinkedIn, Naukri, Indeed, Glassdoor, foundit, Google Jobs and Wellfound use the same filters.

How it works: `api/jobs.js` is a Vercel serverless function. The page calls `/api/jobs?source=…` for each platform; Vercel caches each answer (Remotive 6 h, Jobicy and Remote OK 1 h, Adzuna 30 min), which keeps us inside each platform's usage terms. Attribution to every source is shown on the page.

**Turn on India jobs (Adzuna, free):** sign up at the Adzuna developer site, then in Vercel → Project → Settings → Environment Variables add `ADZUNA_APP_ID` and `ADZUNA_APP_KEY`, and redeploy. Until then the Adzuna chip shows "–" and the other platforms still work.

**Post your own openings (referrals, community jobs):** edit `jobs/featured.json` and push. Each job needs `title`, `company`, `location`, `url`; optional `posted` (ISO date), `type`, `salary`, `note`, `expires` (ISO date; the job hides itself after it):

```json
[
  {"title": "GenAI Engineer", "company": "Example Ltd", "location": "Pune, India", "url": "https://example.com/careers/123",
   "posted": "2026-10-29", "type": "Full time", "note": "DM me on Telegram for a referral.", "expires": "2026-11-30"}
]
```

## Features
- Animated lessons with **Pause, Restart and 0.25× – 2× speed** (starts at 0.5×)
- Article lessons with diagrams, live demos, copyable code and a quiz
- **Hover definitions** for key terms, a full **glossary** and module **cheat sheets**
- **Light and dark themes** (☀ / ☾ button, remembered per browser)
- Topic pages, search across all lessons, and **progress tracking** ("Mark as done", saved in your browser)
- Works on phones, tablets and desktops
- Plain HTML, CSS and JavaScript: no build step, no framework, no backend

## Run locally
Clone the repo and open `index.html` in your browser:
```bash
git clone https://github.com/ajeetkumarAI/learn24.git
cd learn24
# double-click index.html, or serve it:
npx serve .
```

```
api/jobs.js                Serverless job feed (Vercel function)
jobs/                      Live AI jobs page + featured.json
langchain-course/notebooks Colab notebooks (.ipynb) for the LangChain labs
vercel.json                Clean URLs on Vercel
```

## Add a new lesson
1. Create `<topic>/<lesson-id>.html`. The quickest way is to copy an existing lesson and edit its `window.LESSON = {...}` steps.
2. Make sure these lines come just before `</body>`:
   ```html
   <script src="../assets/data.js"></script>
   <script src="../assets/lesson.js" data-lesson="<topic>/<lesson-id>"></script>
   ```
3. Add the lesson to its topic in `assets/data.js` with `status: "live"`.
4. Commit and push. Vercel redeploys automatically.
