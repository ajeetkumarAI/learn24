01What an IPv4 address looks like

IPv4 = 32 bits, written as four numbers (octets) separated by dots. Each octet is 8 bits, so it can be 0 to 255.

02Binary ⇄ decimal: the easy trick

Each of the 8 positions has a value. Start at 1 and keep doubling: 128, 64, 32, 16, 8, 4, 2, 1. Add the values wherever the bit is 1. All eight 1s = 255.

Decimal → binary: go through 128, 64, 32… If the value fits in what is left, write 1 and subtract; otherwise write 0. Example 192: 128 fits (64 left), 64 fits (0 left), rest 0 → 11000000.

05Subnet mask and CIDR

An IP address has a fixed part (the network) and a changing part (the devices). The subnet mask marks them: 255 = network, 0 = device. CIDR is the short form: count the 1-bits in the mask.

🎯 Exam corner
  • A /24 subnet in AWS gives 251 usable IPs (256 − 5).
  • VPC and subnet sizes in AWS: from /16 (65,536) to /28 (16).
  • /32 = exactly one IP (e.g. “My IP” in a security group). 0.0.0.0/0 = everyone.

06Why IP addresses were divided up

If whole first-octet networks like 1.x.x.x (16.7 million addresses) were given to single companies, there would be room for only about 255 companies, and most addresses would be wasted. So IANA (which allocates addresses) and the IETF (which writes internet standards) divided addresses into classes of different sizes. That is Day 7.

What came after: in 1993 the internet moved to CIDR (any prefix length, not only /8, /16, /24). AWS uses CIDR everywhere. IPv4 running out is also why IPv6 (128-bit) exists, and since February 2024 AWS charges for every public IPv4 address.

07Summary

  • IPv4 = 32 bits, four octets, each 0–255.
  • Binary place values: 128 64 32 16 8 4 2 1; add where the bit is 1.
  • First address = network ID, last = broadcast; neither goes to a device.
  • Subnet mask: 255 = network, 0 = host; CIDR /n counts the network bits; addresses = 2^(32−n).
  • AWS reserves 5 IPs per subnet: a /24 gives 251.
