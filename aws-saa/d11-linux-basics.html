Linux Introduction & Navigation Commands

⏱ 13 min read🎯 Beginner friendly🖼 2 diagrams🧪 2 live demos

You are logged in to a Linux server. Now what? This lesson teaches you to read the prompt, become root safely, understand the directory tree and move around. Every command can be tried in the practice terminal below, so you can learn without breaking anything.

In this session

  • Why Linux, and default users per distribution
  • Reading the prompt: user, host, directory, $ or #
  • Switching users: sudo -i, exit, whoami
  • / vs /root vs ~ (the three that confuse everyone)
  • pwd, cd, ls, ll, clear, history
  • A practice terminal

01Why Linux?

Linux is a free, open-source operating system. It runs most of the world’s servers and most EC2 instances because it is free, stable, secure and light. On servers it is used through the command line.

02Reading the prompt

CommandWhat it does
whoamiwhich user am I?
sudo -i or sudo su -become root with a fresh login (go to /root); $ becomes #
sudo subecome root, stay in the same folder
exit or Ctrl + Dgo back to the previous user
sudo <command>run just one command as root (best practice)
🔑

sudo = borrowing the manager’s master key. You are an employee ($). For one task you borrow the master key (#). Give it back (exit) when done.

🎯 Exam corner
  • $ = normal user, # = root. / = root directory, /root = root’s home, ~ = current user’s home.
  • Work as a normal user and use sudo only when needed (least privilege).
  • Check /var/log/cloud-init-output.log to see whether your EC2 user data script ran.

05Summary

  • Linux runs most cloud servers; default users: ec2-user (Amazon Linux) and ubuntu.
  • Prompt: user@host:directory$; $ normal, # root.
  • sudo -i to become root, exit to return, whoami to check.
  • / top of the tree, /root root’s home, ~ your home.
  • pwd, cd, ls -a, ll, clear, history.
