IP Classes, Public vs Private & DHCP

⏱ 14 min read🎯 Beginner friendly🖼 1 diagram🧪 2 live demos🐍 Python code

Yesterday you split an address into network and host parts. Today you see how the internet sized those parts into classes, which ranges are private (free, inside your network) and which are public (on the internet), and how devices get an address automatically with DHCP. Every idea here appears again in AWS VPCs.

In this session

  • Classes A, B, C, D and E by first octet
  • Counting networks and hosts per class
  • Public vs private IPs, and NAT
  • Loopback, APIPA and other special addresses
  • Static vs dynamic IPs, and how DHCP works (DORA)
  • Elastic IPs, NAT gateways and metadata in AWS

01The five classes

ClassFirst octetShapeDefault maskUsed for
A1 – 126N.H.H.H255.0.0.0 (/8)very large organisations
B128 – 191N.N.H.H255.255.0.0 (/16)medium / large companies
C192 – 223N.N.N.H255.255.255.0 (/24)small offices and homes
D224 – 239no splitnonemulticast
E240 – 255no splitnoneresearch

N = network octet (fixed), H = host octet (changes). 127 is missing on purpose: it is reserved for loopback.

🏘️

Buildings and flats. Class A = few buildings, each with millions of flats (huge organisations). Class C = many small buildings with 254 flats each (small offices).

Windows Command Prompt
ipconfig          # your IP, mask and default gateway
ipconfig /all     # also shows the DHCP server
ping 127.0.0.1    # test your own TCP/IP software
ipconfig /release
ipconfig /renew   # give back the DHCP address and get a new one

06How AWS uses all this

IdeaIn AWS
Private rangesVPCs use them, e.g. 10.0.0.0/16 (size /16 to /28)
Public IPauto-assigned public IPs change on every stop/start
Static public IPElastic IP: stays the same until you release it
NATNAT Gateway lets private-subnet servers reach the internet without being reachable from it
DHCPevery EC2 instance gets its private IP from the VPC’s built-in DHCP
Link-local169.254.169.254 = instance metadata service (use IMDSv2)
🎯 Exam corner
  • Public IP must not change after stop/start → Elastic IP.
  • Private servers need updates but must not be reachable → NAT Gateway.
  • Since February 2024 every public IPv4 address is charged, so release unused Elastic IPs.

07Summary

  • Classes by first octet: A 1–126, B 128–191, C 192–223, D multicast, E research.
  • Usable hosts: A 16,777,214 · B 65,534 · C 254.
  • Private ranges: 10/8, 172.16/12, 192.168/16; NAT shares one public IP.
  • 127.x = loopback; 169.254.x = APIPA (no DHCP).
  • DHCP = automatic IPs via DORA; AWS: Elastic IP, NAT Gateway, VPC DHCP.
