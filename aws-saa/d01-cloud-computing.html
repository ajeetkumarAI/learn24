Introduction to Cloud Computing & AWS

⏱ 10 min read🎯 Beginner friendly🖼 4 diagrams🧪 1 live demo

Imagine you want to start an online shopping website like Amazon or Flipkart. You need servers, storage, a database, networking and the internet. Buying all of that yourself is slow and very expensive. Cloud computing lets you rent it instead, by the hour. This first lesson explains the problem, the solution and where AWS fits.

In this session

  • The problem: the cost of traditional IT (CapEx and OpEx)
  • What cloud computing is, in one line
  • How we moved from server rooms to global data centres
  • What AWS is and what it offers
  • Key ideas for quick revision

01The problem: traditional IT

Before the cloud, every company had to build its own on-premises (own building) setup. Look at everything you had to pay for:

WordMeaningExample
CapEx (Capital Expenditure)big money paid upfront to buy things you ownbuying 3 servers for ₹21 lakh
OpEx (Operational Expenditure)regular money paid to run thingsmonthly electricity, rent, repairs
The core problem: huge upfront cost and daily maintenance made startups spend their time and money on infrastructure instead of on their product and customers.

02The solution: cloud computing

Cloud computing = renting computing resources (servers, storage, databases, networking, software) over the internet and paying only for what you use (pay-as-you-go).
💡

Like electricity. You don’t build a power plant at home. You plug in, use what you need, and pay the monthly bill. The cloud does the same for computers.

BenefitWhat it means for you
No big upfront costno ₹21 lakh server purchase; start with a few rupees
Pay-as-you-gopay per second or hour, like a taxi meter
Focus on your productAWS handles the building, power, cooling and broken disks
Scale in minutesadd 100 servers for a sale, remove them the next day
Go globalrun your app close to users in India, the US or Europe

03How we got here

StageWhat happened
Early dayshosting companies and early software-as-a-service (Salesforce, 1999) offered limited online services
2006Amazon launches AWS with S3 (storage) and EC2 (servers), the start of modern public cloud
Todaybig cloud platforms: AWS, Microsoft Azure, Google Cloud, Alibaba Cloud, Oracle Cloud

04What is AWS?

Amazon Web Services (AWS) is the world’s most widely used cloud platform. It offers 200+ services that you combine like LEGO blocks to build almost any application.

🎯 Exam corner
  • Cloud turns CapEx into OpEx (variable expense).
  • Key cloud benefits: no upfront cost, pay-as-you-go, scale on demand, go global in minutes, stop guessing capacity.

05Summary

  • Traditional IT = big CapEx (buy) + ongoing OpEx (run) + people.
  • Cloud computing = rent IT resources over the internet, pay-as-you-go.
  • Benefits: no upfront cost, scale in minutes, focus on your product, go global.
  • AWS (since 2006) offers 200+ services: compute, storage, networking, databases, security and more.
