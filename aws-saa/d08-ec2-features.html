Like renting a car. Pick a model (small hatchback or big SUV), use it as long as you need, return it, and pay only for the time you used it.

03Instances, AMIs and instance types

Instance lifecycle: launch → pending → running ⇄ stopped → terminated. Stop = like shutting down (disk kept, no compute charge, disk still billed). Terminate = deleted forever. Linux is billed per second (minimum 60 seconds).

AMI sourceExamples
AWS-providedAmazon Linux 2023, Ubuntu, Red Hat, Windows Server
AWS Marketplaceready images from vendors (WordPress, firewalls), sometimes paid
Communityshared by others: check carefully
My AMIsmake your own from a configured instance, then launch identical copies

The instance type sets CPU, memory, storage, network and GPU. Decode any name here:

Demo · Instance type decoder

Memory trick: C = CPU, R = RAM, I = I/O (disk), G = graphics, T = tiny / burstable.

05Key pairs, security groups, tags and Elastic IPs

Security group rulePortSource
SSH (admin login, Linux)22My IP only, e.g. 49.36.10.5/32
HTTP (website)800.0.0.0/0 (anyone)
HTTPS (secure website)4430.0.0.0/0
Outbound: all trafficall0.0.0.0/0 (default)
  • Security groups have allow rules only: no “deny”.
  • Default: all inbound blocked, all outbound allowed.
  • Stateful: if a request is allowed in, its reply is allowed out automatically.
  • Tags are labels like Name=web-01, Env=prod; used for search, cost tracking and access control.
  • Elastic IP = a fixed public IPv4 address; release it when unused (it is charged).

🎯 Exam corner
  • Data must survive stop/start → EBS. Fastest temporary disk → instance store.
  • Interruptible batch → Spot. Steady 24×7 → Savings Plans / RIs.
  • Launch many identical servers → custom AMI. Fixed public IP → Elastic IP.

07Summary

  • EC2 = virtual servers on demand; an instance is one server.
  • Pick an AMI (OS), instance type (hardware), EBS or instance store (disk), key pair (login), security group (firewall), VPC/AZ (network, location), tags (labels), Elastic IP (fixed IP).
  • Instance names: family + generation + attributes + size (m7g.large).
  • Pay with On-Demand, Savings Plans/RIs (up to ~72% off) or Spot (up to ~90% off).
