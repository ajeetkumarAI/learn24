Introduction to Networking

⏱ 13 min read🎯 Beginner friendly🖼 3 diagrams🧪 1 live demo

Every AWS resource (a server, a database, a load balancer) talks to others over a network. Later you will build your own private network in AWS, called a VPC. To design one, you first need the basics: what a network is, the devices that build it, and how IP addresses and ports find the right machine and service.

In this session

  • Network vs networking
  • PAN, LAN, CAN, MAN and WAN
  • Network devices: NIC, hub, switch, router, firewall
  • Protocols, IP addresses and port numbers
  • How each idea maps to AWS

01Network vs networking

Every device needs a NIC (Network Interface Card) to join a network. In an office, the devices usually connect to a switch in the middle.

04Protocols, IP addresses and ports

WordMeaning
Protocola set of rules for communication (grammar for computers)
IP (Internet Protocol)the basic rules for moving data from one device to another using addresses
IP addressa logical address for a device: 32-bit (IPv4, e.g. 192.168.1.10) or 128-bit (IPv6)
MAC addressthe physical address burned into the NIC
🏠

IP address = building address; port = flat number. The IP address finds the right machine; the port number finds the right service (website, SSH, database) on that machine.

PortServiceWhere you will use it
22SSH: remote login to LinuxDay 10
80HTTP: websitesDay 12
443HTTPS: secure websiteseverywhere
3389RDP: remote desktop to WindowsDay 9
3306MySQL databasedatabases module
Note: ports belong to TCP and UDP, which run on top of IP. IP finds the device; TCP/UDP ports find the service. Ports go from 0 to 65535.

🎯 Exam corner
  • Switch → MAC addresses, inside a LAN. Router → IP addresses, between networks.
  • “Users can’t reach the website” → check the security group allows port 80/443.

06Summary

  • Network = connected devices; networking = their communication.
  • Sizes: PAN < LAN < CAN < MAN < WAN; the internet is the biggest WAN.
  • Switch delivers inside a LAN; router connects networks; firewall allows or blocks.
  • IP address finds the device; port finds the service (22 SSH, 80 HTTP, 443 HTTPS, 3389 RDP).
  • AWS versions: VPC, subnets, route tables, internet gateway, security groups.
