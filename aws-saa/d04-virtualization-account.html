How can AWS rent you “part of a server” by the hour? The answer is virtualization: one physical machine acting as many virtual machines. In this lesson you see the waste problem it solves, how hypervisors work, what AWS uses (Nitro), and then you create and secure your own AWS account.

01The waste problem (a Netflix-style example)

A streaming app needs a web server (app download), an app server (sign-up, logic) and a database server (user data). We keep them on separate machines for security and so one crash doesn’t take down everything. Each server costs about ₹7 lakh, so ₹21 lakh in total.

We paid ₹21 lakh but use only about one-sixth of the hardware. Roughly ₹17.5 lakh sits idle. Virtualization fixes this: run all three as separate virtual machines on one physical server, still isolated from each other.

02What is virtualization?

Virtualization: one physical machine acting as multiple virtual machines (VMs).
🏢

Like a big hall with movable walls. One building is divided into three rooms. Each group feels it has its own room, with its own door and lock, but it is one building with one electricity bill.

WordMeaning
Hostthe real physical machine
Hypervisorsoftware that splits the host into VMs and keeps them apart
Virtual machine (VM)a “computer inside a computer” with its own OS and apps
Guest OSthe operating system inside a VM
Virtual hardwarethe CPU, RAM and disk the hypervisor gives each VM

03AWS Nitro, and VMs vs containers

  • Every EC2 instance you launch is a VM running on the Nitro System in an AWS data centre.
  • Nitro moves networking and storage onto dedicated Nitro Cards, leaving a very thin hypervisor, so almost all of the server’s power goes to customers.
  • AWS staff have no shell access to Nitro hosts running your instances.
  • Bare-metal instances (e.g. m7i.metal-24xl) give you the whole physical server with no hypervisor.

05Summary

  • One app per physical server wastes most of the hardware (only ~17% used in our example).
  • Virtualization: one physical machine runs many isolated VMs, managed by a hypervisor.
  • Type 1 (bare-metal: ESXi, Hyper-V, Nitro) for data centres; Type 2 (VirtualBox) for laptops.
  • Every EC2 instance is a VM on AWS Nitro.
  • After creating your account: MFA on root, budget alert, IAM user, stop using root.
