04Lab: IIS on Windows

Demo · Do it yourself
PowerShell (as Administrator): the fast way
Install-WindowsFeature -Name Web-Server -IncludeManagementTools
Set-Content -Path C:\inetpub\wwwroot\index.html -Value "<h1>Hello from IIS on EC2</h1>"
Common trap: Windows hides file extensions, so your file may really be index.html.txt. Turn on View → Show → File name extensions.

05Lab: Apache on Ubuntu (and Amazon Linux)

Ubuntu
sudo -i                       # become root
apt update -y                 # refresh the package list
apt install apache2 -y        # install the Apache web server
systemctl start apache2       # start it now
systemctl enable apache2      # start it automatically after every reboot
systemctl status apache2      # should say "active (running)"  (press q)
cd /var/www/html/
rm -f index.html              # remove the default page
nano index.html               # type your page, then Ctrl+X, Y, Enter
index.html
<h1>Hello from my Ubuntu web server on AWS!</h1>
<p>Served by Apache on EC2.</p>
Amazon Linux 2023
sudo -i
dnf install httpd -y
systemctl start httpd
systemctl enable httpd
echo "<h1>Hello from Amazon Linux</h1>" > /var/www/html/index.html
CommandMeaning
apt / dnfpackage managers (app store for the command line) on Ubuntu / Amazon Linux
systemctl startstart a service now
systemctl enablestart it automatically at boot
systemctl statusis it running?
Automate it: paste the Amazon Linux commands (without sudo -i, starting with #!/bin/bash) into User data when launching, and the instance becomes a web server by itself on first boot.

06Troubleshooting and the production way

Demo · What went wrong?
  • A static site (HTML/CSS/JS only) can be hosted on Amazon S3 + CloudFront with no server at all.
  • Keep SSH/RDP closed to the world; open only 80/443. Patch regularly.
  • Logs: /var/log/apache2/ (Ubuntu), /var/log/httpd/ (Amazon Linux), C:\inetpub\logs\LogFiles (IIS).
🎯 Exam corner
  • Website on EC2 unreachable → security group must allow 80/443.
  • Install software automatically at launch → user data.
  • Static website, no servers → S3 static website hosting + CloudFront.
  • Spread traffic over servers → Elastic Load Balancer.

07Summary

  • Folders: mkdir -p, mv, cp -r, rmdir, rm -rf (no recycle bin!).
  • Files: touch, cat (view), > overwrite, >> append; editors nano and vi (i, Esc, :wq, :q!).
  • Website on EC2: open port 80, install IIS or Apache, put index.html in wwwroot or /var/www/html.
  • systemctl start now, enable at boot.
  • Production: load balancer + Auto Scaling + HTTPS; static sites on S3 + CloudFront.
