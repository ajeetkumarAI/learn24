05Troubleshooting and safer access

ProblemLikely causeFix
RDP times outsecurity group doesn’t allow 3389 from your IPadd inbound rule RDP, TCP 3389, source My IP
Worked yesterday, not todayyour home/office public IP changedupdate the rule with your new IP
Wrong address after restartpublic IP changed on stop/startuse the new IP or an Elastic IP
“Password not available yet”Windows still setting upwait 4–5 minutes
Can’t decrypt passwordwrong .pem, or not RSAuse the key chosen at launch; RSA for Windows
Very slow desktopt3.micro has 1 GiB RAMfine for practice; use t3.medium+ for real work
  • Never leave RDP (3389) open to 0.0.0.0/0: it is one of the most attacked ports.
  • Best: Systems Manager Fleet Manager (RDP in the browser) needs no open port and no public IP, and every session is logged.
  • Windows AMIs are License Included; bringing your own licence (BYOL) usually needs Dedicated Hosts.
🎯 Exam corner
  • Windows → RDP, 3389; Linux → SSH, 22.
  • Windows admin password → decrypt with the key pair’s private key.
  • Access without open ports or bastion hosts → Systems Manager (Session/Fleet Manager).

06Summary

  • OS = interface between user and hardware; GUI vs CLI; client vs server OS.
  • Windows EC2: RDP, port 3389, Administrator, RSA key pair decrypts the password.
  • Connect with mstsc (or MobaXterm) using the public IP.
  • Restrict 3389 to My IP or use Fleet Manager; terminate after practice.
