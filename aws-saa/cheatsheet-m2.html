Module 2 cheat sheet: Networking Foundations

IP addresses find devices, ports find services, and CIDR blocks size the networks you will build as VPCs.

All modules📖 Glossary

Key ideas

  • PAN < LAN < CAN < MAN < WAN. Switch = inside a LAN (MAC); router = between networks (IP). Day 5 →
  • IPv4 = 32 bits, 4 octets of 0–255. Bits: 128 64 32 16 8 4 2 1. Day 6 →
  • First address = network ID, last = broadcast: never for devices. Day 6 →
  • Private ranges: 10/8, 172.16/12, 192.168/16; NAT shares one public IP. Day 7 →
  • DHCP gives IPs automatically: DORA. Day 7 →

Common mistakes

  • Overlapping VPC CIDRs that can never be connected later.
  • Forgetting AWS reserves 5 IPs per subnet.
  • Opening SSH/RDP to 0.0.0.0/0.
  • Thinking IP itself uses ports (TCP/UDP do).
