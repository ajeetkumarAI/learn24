Common mistakes

  • Instance store for data that must survive a stop.
  • Losing the .pem file (AWS keeps no copy).
  • Wrong SSH user (ec2-user vs ubuntu).
  • RDP/SSH open to the whole internet.
  • Leaving Windows instances or Elastic IPs running.
